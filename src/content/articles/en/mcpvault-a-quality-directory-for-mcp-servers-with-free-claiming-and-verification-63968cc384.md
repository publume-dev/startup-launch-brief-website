- MCPVault is an independent quality directory for MCP servers, listing over 5,000 servers with quality grades from A to F, staleness signals, install commands, and client compatibility.
- Verification spawns the server and runs an actual MCP handshake (initialize + tools/list).
- Verified servers earn a do-follow link and an embeddable README badge.
- Maintainers can claim their listing with GitHub sign-in in under a minute; claiming and verification are free during early access.

The directory may help developers find reliable MCP servers, but the self-reported nature of the listing is a caveat.
