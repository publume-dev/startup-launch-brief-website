- Flare is a graph-first IDE for agentic coding that visualizes files as nodes and imports as edges, with a live-updating graph reflecting agent edits in real time.
- Flare attributes every write to the responsible agent, detects rewrites of imported files, and snapshots change bursts to local history for diffing and reverting.
- Flare supports running Claude, Codex, and OpenCode from a built-in terminal and integrates agents via MCP from a board; it is local-only, requires no account, and is MIT licensed.
