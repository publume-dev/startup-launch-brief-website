- infr.ad offers a free, OpenAI-compatible API with no credit card, billing, or trial; costs are covered by occasional ASCII ads in terminal responses.
- Requests using tools, structured output, or long system prompts are exempt from ads, so agent tools like aider, Cursor, and Continue are unaffected.
- Users sign in with GitHub and receive an API key in about a minute; the service provides three models across two environment variables.

The service could introduce a new monetization model for developer tools by embedding ads into their output, though no independent verification of its performance, reliability, or ad frequency is yet available.
